## 特殊收容措施

### 一、原典零接触监守与拔摩预案（依据 DrClef 原典）

依据 DrClef 提案原典，鉴于 SCP-001 的固有特性与不可动摇的静止姿态，基金会既无法也无需对其施作任何物理封锁或主动收容措施。常规处置仅限自一处预设安全观测点（编号 **Site 0**）在至少 **10 公里以外**执行全天候 24 小时远程监控。

Site 0 的确切经纬度被列为基金会最高密级地理坐标，全球仅有两人获准知情：现任 SCP 总管（The Administrator），以及由监督者议会指派常驻 Site 0、信奉亚伯拉罕系宗教的单一监督者级特工（编号 **O5-14**）。该监督者获授临机专断权，一旦 SCP-001 出现任何姿态改变或活动迹象，须立刻向总管及全体监督者拉响警报——任何异动都可能意味着 **PATMOS XK 级世界末日情景** 的开端。

“拔摩紧急命令（Emergency Order Patmos）”系列的解码算法仅由 Site 0 值守观察员贴身保存，严禁提前抄录外传，唯有在 SCP-001 转为活跃状态时方才向全球各基金会办公室播发。凡在各类拔摩变体预案中担负关键职能的职员，原典均明确规定四项常态备勤守则：

- 与一个或多个有组织的亚伯拉罕系宗教团体维持良好关系。
- 随身备妥应急物资袋（bug-out bag），并常备圣水、念珠、十字架、祈祷毯或其他经主教及同等以上阶位亚伯拉罕系神职人员祝圣的宗教器物，以及至少一部亚伯拉罕系经典（《妥拉》《圣经》或《古兰经》）。
- 针对“千禧年前被提（premillennial rapture）”情景的潜在人事空缺，每名核心执行官须提前指定一名非亚伯拉罕系信仰的副手，向其告知拔摩文本副本与模因抹杀剂免疫针的存放位置，并保持待命状态以便随时接管职务。
- 熟知其他所有可能卷入 PATMOS XK 级连锁情景的异常项目档案。

此外，原典附录 001-aa 载有总管颁布的永久行政禁令：绝对禁止对 SCP-001 开展任何后续实验，严禁将任何其他 SCP 项目暴露于 SCP-001 视野之内，严禁企图利用 SCP-001 销毁高危异常体。

### 二、大浸染纪元外围监测与航道禁区 `[本站设定]`

在 [[codex-tinctura|大浸染纪元]] 全球基准休谟持续下沉的百年格局中，两河交汇地带成为欧亚非交界处罕见的反向极端异常区：此处既非因低休谟坍缩而被划作 V 级禁区，也不可供人类建城居住，而是受 SCP-001 散发的 8.90 Hm 极端高休谟场与强阿基瓦场笼罩的“绝对静默极点”。

在严格不触碰 Site 0 独立保密体系的前提下，[[goi-tactical-theology|战术神学部]] 与 [[goi-foedus-caeruleum|蓝印盟约]] 铜版测绘局在两河下游 12 公里外沿冲积石堤设立了外围无人水文浮标带，并仅准许无武装无人观测艇沿主航道外侧定期巡航（严禁任何载人船只、飞行器或光学测距激光越过 5 公里警戒圈，更严禁抵近 1 公里必杀界）。所有进入下游河谷的清道队巡查员须提前移除一切非必要电子光学增强镜，防止在远距离误触心灵指令导致任务记忆断片。

## 项目描述

### 一、形态尺数、光翼与武器 SCP-001-2（依据原典）

按照 DrClef 提案原典，SCP-001 为一尊伫立于底格里斯河与幼发拉底河交汇地带未公开位置的人形发光实体。原典所记实测身高约为 **700 肘尺（700 cubits，按古近东标准肘尺折算约 310 至 360 米）**——本档案馆旧版简报曾误将其记为“三百肘尺”并误写为“立于高崖之上”，经核对原典与实测地形（古尔奈两河交汇冲积平原实测海拔仅 4 米，并无百米陡崖），本卷宗已予正式更正。

实体周身自双肩、背部、太阳穴、脚踝及手腕等处生出若干发光的翼状附肢。由于目视强光畸变与观测者认知差异，基金会迄今未能确定翼状附肢的精确数目；各批次观测报告的计数跨度由最少 **2 翼** 直至最多 **108 翼**，统计学均值则稳定落在 **4 翼**。

实体双手紧握一柄形似长剑或巨刃的武器（编号 **SCP-001-2**）。光谱仪分析显示，刃身喷吐的火焰温度堪比太阳表面，但令人费解的是，这种恒星级高温对周围空气、河水、芦苇与河岸泥土完全不产生任何热力学灼烧或蒸发效应。SCP-001 始终维持同一静止姿态：头颅低垂如祈祷或俯首状，双手握持剑柄，将 SCP-001-2 剑尖垂直向下抵于身前。自基金会创始人于 `[数据删除]` 年前首次记述该实体以来，其站姿从未发生过哪怕一毫米的偏斜。

### 二、一公里绝杀半径与心灵指令机制

SCP-001 的防御边界呈现绝对刚性，且严格区分“误入者”与“越界/敌对者”——这一点亦是旧版简报常被混淆之处：

- **心灵指令（非致死劝离）**：人类目视或进入 SCP-001 的感知覆盖圈时，颅内会直接响起一道无法违抗的指令。最常见的指令为 **“遗忘（FORGET）”**，受影响者会转身平静走开，并且彻底丧失曾遭遇 SCP-001 的全部记忆，身体毫发无损。在实测 A 中，一名 D 级人员则收到了 **“离开（LEAVE）”** 的指令。仅在极罕见情形下，实体曾发出过其他指令——最著名的例证是它向基金会创始人传达的那句 **“预备（PREPARE）”**，正是这道指令直接促成了创始人建立专门机构以编目并收容一切威胁人类存续的超自然之物，亦即今日 SCP 基金会的缘起。
- **一公里抹除与全向反击**：任何实体（无论生物、无人机或制导兵器）一旦跨入距 SCP-001 不足 **1 公里** 的半径，即刻遭到 SCP-001-2 挥斩并从物理存在层面彻底抹除。任何针对 SCP-001 发起的敌对攻击，无论发射阵地远在何处、距离多少公里，均会招致攻击者连同发射平台被同步湮灭。旧版简报曾将心灵指令误写为“遗忘，或归于原初群青并瞬间原子化”，其中“归于原初群青”实属本站早期风格化误植，且混淆了和平劝离指令与 1 公里武力抹除边界，现已严格剥离。

### 三、巨门之后与创始人的文献考证

长期的远距长焦摄影证实，SCP-001 身后矗立着一座体量惊人的宏伟巨门。在极少数大气视宁度极佳的相片中，镜头曾透过门扉缝隙隐约捕获到门后景象：那是一片宁静的田园树林，林间栖息着众多与 SCP-001 构成材质相似的发光实体，并生长着数株成分不明的果树。树林中央附近耸立着两棵体格格外高大的巨树——其中一株外观酷似寻常苹果树，另一株结出的果实则在地球植物谱系中毫无对应，其细节在原典中遭彻底抹除。

基金会创始人通过比对古代巴比伦泥板文献与死海古卷，坚信 SCP-001 所扼守的正是 `[已删除]` 之门，并据此推论 SCP-001 本体的身份。出于尊重现存宗教传统与原典克制原则，本档案馆不将任何现存真实宗教场所与异常巢穴挂钩，仅如实保留原典中“未公开两河交汇点”与“创始人文献比对推论”之原始表述。

## 发现经过与前情沿革

### 一、创始人的“预备”启示与 Site 0 的静默百年

在 DrClef 提案确立的基金会创世叙事里，SCP-001 并非众多异常中被偶然编入第一号的普通项目，而是基金会诞生的起点本身。当年创始人于两河流域亲历守门人显现，未像常人那样收到“遗忘”，而是接获了唯一一词“预备”。在原典逻辑下，此后数代人修筑的收容站点、制定的收容等级与庞大的保密机器，归根结底都是在为那扇始终未曾开启的巨门做不知归期的筹备。

也正因如此，实验 A 至 G 构成了一段极具讽刺意味的机构失衡史：当后继研究者试图以冷战式的武器测距、饱和无人机突防甚至跨项目处决来试探守门人底限时，每一次试探换来的都不是数据突破，而是连带发射阵地在内的彻底清零。直到 SCP-076 的罕见退缩与 SCP-073 额头印记引发的失控危机，总管才彻底锁死了对 SCP-001 的主动干预渠道。

### 二、来自未来的拔摩-欧米茄错位电文

在原典最末，一段来历不明的失真电文打破了 Site 0 持续百年的绝对静止。该电文伪装成自 Site 0 发出的紧急广播，宣告 SCP-001 已离开原位、巨门洞开，并要求全员解码执行“拔摩-欧米茄（PATMOS-OMEGA）”。尽管随后核实 Site 0 的 O5-14 从未发送该信号、守门人依旧纹丝不动，但技术部门在对载波元数据进行深层溯源时，发现了令人脊背发凉的异常——这份电文携带的时间戳指向**未来 `[数据已编辑]` 年之后**。

## 现状与大浸染纪元对策 `[本站设定]`

### 一、8.90 Hm 孤峰：为什么两河口无法改建成第八座圣城

进入 [[codex-tinctura|大浸染纪元]] 后，全球地表休谟均值持续跌落，[[goi-foedus-caeruleum|蓝印盟约]] 内部一度涌现过一项颇具诱惑力的激进提案：既然两河交汇地带天生拥有高达 **8.90 Hm** 的极端高休谟场，远胜 [[sanct-sol|亚历山大圣座]] 的 1.80 Hm 与 [[site-2000|黄石巨构]] 的 1.35 Hm，能否在距守门人 5 公里外的河谷兴建一座无需消耗古典行星时辰的“天然第八圣城”，甚至通过超导谐振桩向周边中东走廊抽取冗余现实密度？

[[goi-ordo-caeruleus|赫尔墨斯蓝色修会]] 与 [[goi-tactical-theology|战术神学部]] 在 2009 年联合提交了否决报告，理由基于三条冷硬的物理测量数据：

- **休谟过饱和与因果僵死**：人类神经突触与常规生物化学反应的最适休谟区间为 0.95 至 1.85 Hm。在超过 3.50 Hm 的强场区内，量子隧穿概率受到剧烈压制，热力学扩散变慢；而 SCP-001 核心外缘实测达 8.90 Hm，在该梯度内普通金属晶格都会发生不可逆脆化，活体人员即使不被火焰剑抹除，也无法在超过 4.00 Hm 的持续高场中存活。
- **阿基瓦辐射极性互斥**：[[codex-hume-theory|蓝色神学]] 所用的群青谐振腔遵循去位格化的几何比例律，而两河口散发的是高度位格化、具备明确神学指向的强阿基瓦辐射（峰值曾突破 6,400 Ak）。2009 年试放的两座无人青金石谐振浮标在距离 4.2 公里处刚一通电，内部八角铜腔即发生无热裂解，像被一只无形的手从晶体结构里轻轻抹平了所有蚀刻刻痕。
- **绝对不可试探原则**：原典附录 001-aa 的总管禁令在大浸染纪元依然具有最高效力。任何试图向守门人“借电”或“借场”的工程，本质上都属于主动触碰实体边界，一旦被判定为敌对行为，代价可能是连同亚历山大母钟在内的整条中东电网被一并抹除。

### 二、遥测事件 `001-伊甸` 与 Site-13 平行收容的惊悚对照

2021 年深秋，当孟加拉湾—印度洋深海沟（[[site-3000-bengal|Site-3000]] 远海方向）记录到一次剧烈的非地震性深海休谟坍缩尖峰时，Site 0 外围无人遥测阵列录下了一段长达 **14 秒** 的异常姿态偏转记录：望远镜阵列上的强光质心向东南深海方位微偏了 0.8 角分，阿基瓦闪烁计读数瞬间飙升至 6,400 Ak 以上，随后一切恢复死寂。由于 O5-14 判定实体并未迈步离开原位，拔摩紧急程序未被触发，但该记录成为自建档以来守门人对地球其他异常极点产生响应的首例仪器佐证（注：本事件纯系本站大浸染纪元虚构遥测设定，与任何现实世界自然灾害无关）。

另一项令战术神学部寝食难安的交叉档案来自 2017 年终结的 [[dossier-scp-1730|SCP-1730（第十三号站点）]] 撤离录像。在平行宇宙基金会与 GOC 合并体修建的地下奥林匹斯级收容室中，MTF Tau-5 与 Zeta-9 曾亲眼目睹一尊高达百米、展开烈焰巨翼、手握火焰长剑的静止人形实体破门而出，与平行世界的鹿神及水蛭巨兽展开混战。尽管两个宇宙的物理法则不尽相同，但那段录像直接击碎了“守门人绝对不可被人类机械所困”的盲目乐观——也反过来证明，在那个傲慢到敢把神性实体装进地下铁箱的平行时间线里，最终迎来的只有整座站点的跨维焚毁。

::: doc type=interview code="附录 001-04" title="下游水文测绘员误视 SCP-001 后的战术神学问询笔录" date="2025-04-03" author="三级战术神学官 L. 纳赛尔（审阅：战术神学部西亚科）" clearance=2 origin=original
**受访者**：测绘技师哈桑·巴德里（铜版测绘局外聘水文船员，2 级清道通行证）  
**事由**：2025-04-02 16:40，三号无人观测艇信号中断，受访者违规驾驶无武装柴油浅水艇驶至距交汇点 4.6 公里处试图目视回收，半小时后自行原路返回石堤。

**纳赛尔**：巴德里，把你昨天下午四点半之后记得的最后一件事再说一遍。

**巴德里**：我把船停在芦苇丛外边，抄起望远镜找三号艇的白色天线。风停了，水面平得像刚抛过光的锡盘。然后……然后我就把船头调转，开回码头的浮桥了。

**纳赛尔**：你拿的是十二倍光学双筒镜。镜筒朝向西北偏北时，你看见了什么？

**巴德里**：（长时间停顿，低头摩挲茶杯沿）长官，你已经问了第四遍。河面上什么也没有，连野鸭都没有。只是日落前的反光太刺眼，晃得我眼睛发酸。我突然觉得三号艇大概已经顺流漂去巴士拉了，没必要再往上游找，就回来了。

**纳赛尔**：你的行船记录仪显示，你在 16:47 把望远镜放回仪表台，随后在空白航海日志第 38 页上用铅笔写了一行字，才掉头返航。你记得自己写过吗？

**巴德里**：我没动过铅笔。我的手当时全沾着柴油。

**纳赛尔**：（将装在透明封套内的第 38 页推过桌面）字迹鉴定是你本人的。上面没有日期，没有坐标，只工整地写了两个英文大写词，又划掉了第二个。第一个是“FORGET”，第二个划掉的词，笔迹极轻，像你手腕完全不受自己控制写下的——“NOT YET”。

**巴德里**：（盯着纸页超过二十秒，面无表情）长官，我不懂英语。我只认识数字和阿拉伯文。这大概是上一任船长留下的草稿吧。

**笔录附记**：经医学与认知筛查，受访者无任何外伤、辐射损伤或模因污染残留，亦完全无法回忆 16:44 至 16:49 之间的五分钟空白。这是大浸染纪元首次在常规“遗忘（FORGET）”指令之外记录到疑似附带时间状语的笔迹残影。原件已封存上呈 O5-14 备查。
:::

::: doc type=memo code="附录 001-05" title="O5-14 机密备忘：关于非亚伯拉罕系副手接管与 Site-13 交叉影像评估" date="2026-11-12" author="O5-14（Site 0 驻守监督者）" clearance=4 origin=original
致总管及战术神学部部长（限绝密纸本阅后即焚）：

两件事需要立刻在年终复核前拍板。

第一，按拔摩程序第三条，我在本月完成了新一任非亚伯拉罕系副手的背景遴选与密匙托管。人选来自 [[goi-miskatonic-yixuehui|中华异学会]] 出身、后转入战术神学部的资深声呐与星历考据员——他既不信奉任何一位天启之神，也对青金石几何持怀疑态度，在所有可能的“被提”或群体宗教狂热情景中都能保持绝对冷酷的抄表纪律。我已将拔摩解码轮盘的副钥封存在他毫不知情的备用装备箱夹层里，只有当 Site 0 连续七十二小时停止发报时，加密电台才会向他推送开启口令。

第二，关于诸位送来的 2017 年得克萨斯 [[dossier-scp-1730|SCP-1730]] 奥林匹斯级收容室撤离影像，我逐帧看了六遍。屏幕里那个破门而出、浑身冒火的持剑巨像，高度、翼数均值与剑身无热辐射的光谱特征，与我每天隔着十公里沙漠凝视的守门人至少有九成吻合。唯一让我彻夜难眠的细节不在那把剑，而在它走出来的那扇金属门——{{redact:4:在平行宇宙的第十三号站点里，有人竟然真的把某种与 SCP-001 同构的存在关进了地下百米混凝土牢房。我无法想象他们付出了怎样的代价才把它从两河口拖进阿拉斯加的冰原，但我很清楚那条道路的终点：那座站点最后连同半个荒漠一起从地球上蒸发了}}。

守门人至今仍低着头，剑尖仍抵着河沙。请转告佛罗伦萨的七曜议会：哪怕明天的全球休谟再往下掉半个百分点，也绝不要对两河口动任何工程上的歪念头。我们对它能做的最稳妥处置，就是退守十公里外，盯着它，然后记住那两个字：预备。

—— O5-14，发自 Site 0
